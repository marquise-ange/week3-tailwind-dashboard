# MediFind — Healthcare Job Portal & Admin Dashboard

## Project Overview

MediFind is a modern, responsive healthcare job portal designed to connect healthcare professionals with career opportunities. The project includes a welcoming home page where users can explore the platform and a dashboard interface for monitoring job applications, tracking progress, exploring employers, and managing profile information.

The design focuses on a clean layout, professional colors, consistent typography, and responsive components to provide a smooth user experience across desktop, tablet, and mobile devices.

## Features

- **Home Page:** Designed a welcoming landing page with clear navigation, an engaging hero section, platform information, featured job opportunities, featured employers, and calls to action.
- **Admin Dashboard:** Created a dashboard layout with an overview of job search statistics, recent applications, recent activity, featured employers, and a profile management form.
- **Responsive Navigation:** Implemented a desktop sidebar and a collapsible mobile navigation menu for easier navigation across screen sizes.
- **Reusable UI Components:** Created reusable styling for buttons, cards, navigation links, and other interface elements to maintain visual consistency.
- **Responsive Layout:** Used Tailwind CSS responsive utilities to adapt layouts, cards, tables, and navigation to different screen sizes.
- **Interactive Visual Feedback:** Added hover effects, focus states, and transitions to improve usability and accessibility.
- **Light and Dark Theme Styling:** Incorporated theme-related styling to support a more flexible interface.

## How I Customized Tailwind CSS

I customized Tailwind CSS to create a clean, modern, and responsive MediFind interface. I extended the default theme with a custom brand color palette featuring shades of teal and dark blue, giving the home page and dashboard a consistent, professional appearance. I also selected typography to improve readability and create a cohesive visual identity throughout the project.

To make my code more organized and reusable, I created custom component classes in my Tailwind CSS entry file using `@apply` inside `@layer components`. These include `.btn-primary` for consistent button styling, `.card` for dashboard cards and content panels, and `.nav-link` for sidebar navigation links. These reusable classes reduce repeated utility classes and make the HTML easier to maintain.

I used Tailwind CSS responsive utilities, including `sm:`, `md:`, `lg:`, and `xl:`, to ensure that both the home page and dashboard adapt to different screen sizes. I also incorporated hover, focus, and transition utilities to improve user interaction and provide visual feedback.

Additionally, I included light and dark theme styling to make the interface more flexible and comfortable to use.
